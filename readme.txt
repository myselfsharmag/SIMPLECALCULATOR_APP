# 🔢 AI Simple Calculator

A simple calculator built with **Python** and **Streamlit**. The application performs basic arithmetic operations and is designed to be easily extendable with AI-powered features using the NVIDIA API and the OpenAI Python SDK.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- User-friendly Streamlit interface
- NVIDIA API integration ready

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI Python SDK
- NVIDIA API

## 📦 Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run simplecalculator.py
```
